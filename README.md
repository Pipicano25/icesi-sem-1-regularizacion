# Regularización (L1 / L2 / Elastic Net)

**ICESI · Máster en Inteligencia Artificial Aplicada**

Exploración de técnicas de regularización en modelos lineales: **Ridge (L2)**, **Lasso (L1)** y **Elastic Net**, y su efecto sobre el sesgo y la varianza del modelo.

## Contenido

| Archivo | Descripción |
|---|---|

| `1_contornos_l1_l2.png` | Contornos de las normas L1 y L2 |
| `2_efecto_lambda_ridge.png` | Efecto de λ en Ridge |
| `3_efecto_lambda_lasso.png` | Efecto de λ en Lasso |
| `4_camino_lasso.png` | Lasso path |
| `5_elastic_net.png` | Elastic Net |
